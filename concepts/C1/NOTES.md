# C1 «Горизонт» — NOTES

Концепт для bmc-gp.com без Tilda: планшет ККС-5, уходящий к горизонту, — хребет обеих страниц;
гамма № 3 концепта — палитра сайта. Сборка детерминированная: `_src/build.js` считает всю графику
по формуле и вклеивает CSS/JS одним блоком; `index.html` и `rd.html` самодостаточны.

## 1. Структура в пяти строках

1. **Главная.** Герой: заголовок + планшет над линией горизонта (наклон по прокрутке) → две программы одной строкой со стадией → три числа (9 / 155 / 357) → кадр A2.
2. 01 Две программы (карточка ККС-5 с планшетом, карточка птицы с линией поения) → 02 Хроника 2026 с ползунком → 03 Комплектация → 04 Биобанк.
3. 05 Качество и матрица девяти методик с фильтром по нормативному документу → 06 Оборудование → 07 Команда (роли) → 08 Партнёрам: переключатель «кто я», четыре карточки, «Как начать», форма → 09 Реквизиты.
4. **/rd.** 01 ККС-5: планшет, чьи пять лунок ближнего ряда отвечают строкам таблицы КП → 01.1 цикл ИФА шестью плитками с шагами → 01.2 хроника и таблица КП → 01.3 стабильность и ИХЛА → 01.4 стадия (один раз) → 01.5 финансирование.
5. 02 Вакцины для кур: идея и инфекции рядом с линией поения, на ближних ниппелях которой стоят четыре этапа плана → задел → целевой профиль → план и стадия → финансирование → 03 Как начать. Разделы разделены полосами-горизонтами из той же формулы.

## 2. Что сохранено из «Прибора» и что изменено

**Сохранено:** восьмиступенная шкала кеглей (12 / 13 / 15 / 17 / 20 / 20 / clamp 26→32 / clamp 31→50), пол 15 px для предложений и 12 px только для ПРОПИСНЫХ меток; ритм 8 px (все интерлиньяжи 16/20/24/28/32, отступы `--s1…--s9`); три роли заголовков; моноширинные табличные цифры на всех числах, косой ноль; шкала с делениями под H1 и под заголовком раздела; компоненты — карточка с кромкой сверху, таблица только с горизонтальными линиями и подписями `data-l` на узком экране, разграфлённый кадр `.ph` с номером кадра, перечень `.spec`, шаги `.steps`, реквизиты `dl`, подвал; `<details>`-меню; радиус 0 (оставлен: прямые углы читаются как планшет и прибор); `--alarm` не определён и не используется; янтарный `--sig` оставлен как токен, но нигде не применён.

**Изменено (гипотеза «Горизонт»):**
- Палитра: бумага `#F3F3EF` → белый `#FFFFFF`, полоса раздела `#E4E5DC` → `#EEF2F8`; чернила выведены из navy гаммы № 3: `--ink #1A2340` (15,5:1 на белом), `--ink-2 #424A63` (8,8:1), `--ink-3 #5A6480` (5,9:1; 5,2:1 на полосе); линовка `#D9E0EA` / `#B9C3D1`. Тёмная панель и подвал — navy `#24305F` (белый текст 12,6:1, `--panel-2 #CBD5EA` 8,6:1, `--panel-3 #A3B2D2` 5,9:1). Все кромки, номера разделов, плашки чисел — navy вместо чёрного. Фирменный синий `#244191` — только подчёркивание ссылок, цвет ссылки при наведении, рамка и буквы слота логотипа, кольцо фокуса. Гамма № 3 (`#24305F`, `#5282BE`, `#97B5DC`, `#A6B1BE`, промежуточный `#749BCD` для пятой лунки) живёт в лунках, маркерах перечней, горизонтах.
- Шрифты: **Rubik** (переменная 400…700; на странице 400 и 600) — заголовки и сплошной текст, **IBM Plex Mono** — числа, метки, меню, подписи. Пара обоснована так: Rubik — шрифт концепта бренда ККС-5, и его мягкие прямоугольные формы совпадают с эллипсами лунок; Plex Mono сохранён, потому что вся приборная дисциплина чисел (табличные цифры, косой ноль) уже на нём и он остаётся общим с текущим «Прибором». Один `<link>` Google Fonts.
- Плашки чисел героя стоят в три колонки, а не в столбик; кадры-заглушки в одиночном положении ограничены 820 px и пропорцией 2:1 (в парах — 16:9, в ленте героя — 21:9), чтобы страница не растягивалась.

## 3. Интерактивные устройства, их поведение без JS и при reduced-motion

Все устройства — инлайн `<script>` в конце страницы; `html.no-js` → `html.js` при загрузке; элементы управления (`.seg`, ползунок, полоса хроники) отрисовываются только при `.js`, поэтому без JS страница не содержит мёртвых кнопок. В консоли ошибок нет (render.js, четыре варианта).

## 4. Формулы

**Планшет 8 × 12 (та же, что в принятой v2, с параметром k).** Ряд r = 0…7 (ближний → дальний), колонка c = 0…11, t = r/7:

    q  = 1 / (1 + k·t),   q₇ = 1 / (1 + k)
    x  = 280 + (c − 5,5)·42·q
    y  = 310 − 250·(1 − q)/(1 − q₇)        (дальний ряд всегда на y = 60)
    rx = 11·q,  ry = 7·q
    линия горизонта: y = 60 − 10 = 50, от x = 0 до 560, цвет #97B5DC

Статическая разметка — k = 1,8 (контроль: well(0,0).cx = 49, well(7,0).cy = 60, rx₇ = 3,929 — совпадает с v2). С JS k = 1,0 + 1,8·s, s — доля прокрутки до планшета (п. 3.1). Цвет по колонкам: c 0–2 navy, 3–5 blue, 6–8 sky, 9–11 grey. Отрицательный контроль: r = 0, c = 0, белая заливка, обводка navy 1,5, rx/ry уменьшены на 0,75. На /rd пять лунок-маркеров: (0,1) `#24305F` HBsAg, (0,3) `#5282BE` анти-HBcore, (0,5) `#749BCD` анти-ВИЧ-1/2, (0,7) `#97B5DC` анти-ВГС, (0,9) `#A6B1BE` анти-*T. pallidum*. Полоса-горизонт между разделами — ряды r = 4…7 той же формулы, `viewBox 0 48 560 72`, не шире 640 px. Полоса хроники — ряд r = 0, семь лунок при c = 11·i/6, радиусы × 1,3.

**Линия поения (мотив вакцин для кур).** Та же сетка и та же q(r); две трубы идут по колонкам c = 2,5 и c = 8,5:

    ниппель r:      эллипс в точке (x(r,c), y(r)), rx = 11·q, ry = 7·q
    ось трубы:      y_p(r) = y(r) − 18·q, полуширина 7·q → полигон из 16 точек r = 0…7 и обратно
    штуцер:         отрезок от y_p до y − ry, толщина 2,5·q
    цвет по глубине: r 0–1 navy, 2–3 blue, 4–5 sky, 6–7 grey; труба #EEF2F8 с обводкой navy
    этапы плана:    ниппели r = 0…3 левой линии, id nip-s1…s4, цифра 1–4 слева (Plex Mono 18)

Горизонт — та же линия y = 50. Наклон по прокрутке пересчитывает ниппели, штуцеры, цифры и полигоны труб.

**Плитки цикла ИФА** (160 × 100, `aria-hidden`): ряд из четырёх лунок rx 10 / ry 6 на y = 84 (цвета гаммы, белая — лунка контроля), сверху — флакон (прямоугольник + эллипс мениска), дозатор и капля, циферблат, четыре пунктирные струи, планка фотометра и луч, столбики КП: высота = КП × 7,33 (4,4 / 6,2 / ≈11 / 3,8), пунктир порога на 3, столбик анти-ВИЧ-1/2 открыт вверх (сигнал выше предела фотометра, числа нет).

- Светлые тона гаммы № 3 (`#97B5DC` 2,1:1, `#A6B1BE` 2,2:1 на белом) ниже 3:1 — это палитра владельца; смысл нигде не несут только они: подсветки, обводки, цифры, контроль — navy; строки таблицы несут текст.
- Наклон планшета при первой отрисовке с JS даёт k = 1,0 вместо статических 1,8 — одно входное изменение на страницу (допустимо по BRIEF_INTERACTIVE §6.9); при reduced-motion его нет.
- Форма отправляется через `mailto:` (как в v2) — обработчик формы и хостинг остаются решениями владельца (OWNER_INPUTS № 28).
- Сборка: `node _src/build.js` пересобирает обе страницы из `_src/*.tpl.html`, `_src/style.css`, `_src/app.js`; результат байт-в-байт воспроизводим.
