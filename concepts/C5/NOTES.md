# C5 — «Карта того, что есть» · NOTES

Сборка детерминированная: `node _src/build.js <папка>` собирает `index.html` и `rd.html` из
`_src/style.css`, `_src/index.js`, `_src/rd.js`; все SVG вычисляются формулами ниже (в `build.js`
есть самопроверка: планшет при k = 1,8 обязан дать well(0,0).cx = 49, well(7,·).cy = 60,
rx = 3,929 — числа принятой версии 2). Внешний ресурс один — Google Fonts. Растров нет.

## 1. Структура в пяти строках

1. **Главная = карта.** Герой: H1 и лид версии 2, под ними сетка из десяти плиток-фактов
   (2 программы · 9 методик · 155 наборов · 357 криобоксов · 29 СОП / 81 форма · −86 °C ×4 ·
   стадия ККС-5 · НИОКТР 16.11.2026 – 31.12.2028 · команда · 4 адресата); каждая плитка —
   якорь на свой раздел (стадия и план — на /rd).
2. Далее разделы версии 2 в том же порядке и с тем же текстом: 01 Две программы (планшет +
   птичник) → 02 Хроника (SVG-шкала со скраббером + список) → 03 Комплектация → 04 Биобанк →
   05 Качество и девять методик → 06 Оборудование (инвентарь по категориям с метками единиц) →
   07 Команда (фильтр по программе) → 08 Партнёрам («кому» + четыре карточки + как начать +
   форма) → 09 Реквизиты.
3. **/rd:** 01 ККС-5 — планшет, перспектива которого следует за прокруткой; 01.1 схема цикла ИФА
   с пошаговым проходом; 01.2 сделано + КП как пять лунок ближнего ряда, связанные с таблицей;
   01.3 стабильность и ИХЛА; 01.4 стадия (одна фраза); 01.5 финансирование.
4. 02 Вакцины для кур — мотив птичника в шапке раздела, 02.1–02.6 версии 2 без изменений;
   03 Как начать.
5. Страницы связаны относительными ссылками (меню, карточки, плитки, подвал); `/privacy`
   остаётся внешней ссылкой.

Нет scroll-jacking, нет оверлеев, нет автозапуска; ни одна анимация не идёт без действия

## 4. Формулы графики

### 4.1 Планшет ККС-5 (8 × 12, гамма № 3) — принятая формула версии 2, без изменений

r = 0…7 (ближний → дальний), c = 0…11, t = r/7:

    q  = 1 / (1 + k·t),  q₇ = 1 / (1 + k),  k = 1,8
    x  = 280 + (c − 5,5)·42·q
    y  = 310 − 250·(1 − q)/(1 − q₇)
    rx = 11·q,  ry = 7·q

Цвет по колонкам: c 0–2 `#24305F`, 3–5 `#5282BE`, 6–8 `#97B5DC`, 9–11 `#A6B1BE`. Лунка
(r = 0, c = 0) — белая с обводкой navy 1,5, rx/ry уменьшены на 0,75 (отрицательный контроль).
Контроль: well(0,0) = (49; 310), ряд 7 — y = 60, rx = 3,929.

**Прокрутка (/rd):** p = clip((vh − top)/(vh + h), 0, 1), где top и h — положение и высота
планшета в окне; k = 1,1 + 1,6·p. При p = 0,4375 k = 1,8. Ближний ряд (q = 1) неподвижен,
дальние ряды сходятся сильнее, когда планшет уходит вверх.

### 4.2 Лунки ближнего ряда с КП (/rd 01.2)

Ряд r = 0 той же формулы: cx = 49 + 42·c, cy = 170 (собственный viewBox 560 × 200), rx 11,
ry 7. c = 0…4 — пять маркеров (navy, blue, `#749BCD`, sky, grey — как в таблице), c = 5…10 —
серые на 40 %, c = 11 — белая с обводкой (отрицательный контроль). Подписи ступенями
y = 28 + 30·i, выноска вертикальная от подписи к лунке. На экранах уже 700 px фигура скрыта
(текст в SVG стал бы мельче 15 px); таблица с теми же лунками-свотчами остаётся всегда.

### 4.3 Мотив вакцинной программы — птичник (ряды поголовья и линия поения)

Та же дисциплина перспективы, другие параметры: R = 6 рядов (ближний → дальний), C = 10
колонок, t = r/5:

    q  = 1 / (1 + k·t),  q₅ = 1 / (1 + k),  k = 1,1
    x  = 280 + (c − 4,5 + s_r)·52·q,   s_r = +0,25 на нечётных рядах, −0,25 на чётных (шахматный сдвиг)
    y  = 300 − 210·(1 − q)/(1 − q₅)
    rx = 14·q,  ry = 6·q
    заливка: r = 0 — #5282BE, r = 1 — #97B5DC, r ≥ 2 — #A6B1BE
    линия поения: x = 280 от (y₀ − 48·q₀) до (y₅ − 48·q₅), navy 2 px;
    ниппели: на каждом ряду отрезок от y_r − 48·q_r длиной 14·q_r, толщина 1 + 1,2·q
    горизонт: y₅ − 12, #97B5DC 1 px

Читается как птичник сверху-сбоку: ряды птицы уходят к горизонту, над центральным проходом
— труба поения с ниппелями. Ни шприца, ни клип-арта, ни медицины.

### 4.4 Шкала хроники

Ось времени: d — число дней от 24.08.2026, диапазон 70 дней до 02.11.2026:

    x = 24 + 552·d/70  (viewBox 600 × 72), ось y = 40
    деления: каждые 7 дней; крупные — 01.09, 01.10, 01.11
    событие: круг r = 6 в x(d_начала); интервал — прямоугольник от x(d₁) до x(d₂), navy 35 %
    подписи месяцев — HTML, left = 100·x/600 %

События: 27–31.08 · 01.09 · 02–04.09 · 04.09 · 08.10 · 16.10 · 28–30.10.

### 4.5 Метки единиц оборудования

Одна единица — квадрат 10 × 10 с шагом 14: viewBox `0 0 (14n − 4) 10`, `rect x = 14·i`.
n — число названных единиц в строке (2 бокса → 2; «Sartorius и Millipore» → 2; 15
рециркуляторов → 15). SVG `aria-hidden`: число всегда есть в тексте строки.
