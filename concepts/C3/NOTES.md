# C3 — «Тёмный планшет». NOTES

Интерактивная версия bmc-gp.com, не на Tilda. Две страницы: `index.html` (`/`) и `rd.html` (`/rd`),
самодостаточные (один `<style>` системы + один `<style>` страницы, один инлайн `<script>`; внешнее — только
Google Fonts). Собираются скриптом из исходников в scratchpad: статические SVG планшета, горизонта,
стада и оси хроники строятся из тех же формул, что рисует canvas на странице (`BMK_GEOM` в скрипте
страницы) — геометрия одна, расхождение невозможно. Текст — проверенный текст версии 2 дословно
(`textdiff`: «missing from candidate 0» на обеих страницах).

## 1. Структура в пяти строках

1. **Главная**: первый экран — кто/где, заголовок, две программы со стадией каждой, три числа (9 / 155 / 357),
   кадр A2; планшет 8 × 12 на canvas во всю ширину героя.
2. 01 Две программы (карточка ККС-5 со вторым планшетом, карточка вакцин для кур) → 02 Что сделано в 2026
   (хроника с ползунком по датам и осью с делениями) → 03 Комплектация и прослеживаемость → 04 Коллекции биобанка.
3. 05 Система качества и методики (матрица девяти методик с фильтром по нормативной привязке) → 06 Оборудование →
   07 Команда (роли).
4. 08 Партнёрам и фондам («кто вы» подсвечивает адресную карточку; четыре светлые плашки; как начать; форма) →
   09 Контакты и реквизиты → подвал.
5. **/rd**: 01 ККС-5 — шапка с планшетом на canvas, договорные требования, 01.1 схема цикла ИФА с шагами 1–6 на
   светлой плашке, 01.2 сделано + пять лунок над таблицей КП (строка ↔ лунка), 01.3 стабильность и ИХЛА, горизонт
   из двух ближних рядов, 01.4 стадия, 01.5 финансирование; 02 Вакцины для кур — мотив «линия поения и стадо»
   с подсветкой по прокрутке, идея → инфекции → задел → целевой профиль → план с датами и стадия → финансирование;
   03 Как начать.

## 2. Что оставлено от «Прибора» и почему; что изменено

**Оставлено** (это и есть узнаваемость системы, она не зависит от цвета фона):
- IBM Plex Sans / IBM Plex Mono, начертания 400/500/600, один запрос Google Fonts — тот же, что в v2.
- Шкала кеглей 12 / 13 / 15 / 17 / 20 / h2 clamp(26→32) / h1 clamp(31→50); 15 px — пол для предложения,
  12 px — только ПРОПИСНЫЕ метки каналов; табличные цифры на `body`, косой ноль в mono.
- Ритм 8 px, те же `--s1…--s9`, поля раздела 48 / 64 / 88, `--maxw 1160`, радиус 0 везде.
- Номер раздела плашкой + **шкала с делениями** под заголовком раздела и под H1 (перекрашена: деления `--lt-3`,
  кромка `--lt`), номер подраздела в рамке.
- Таблицы только с горизонтальными линиями; на узком экране шапка исчезает, подпись поля приходит из `data-l`.
- Разграфлённое поле кадра `.ph` с кодом кадра в углу и подписью, «выбитой» из разграфки.
- Ссылка: текст цветом текста, подчёркивание синим — синий остаётся знаком документа/перехода, не декором.
- Карточка «белая плашка на тёмной панели» (правило «Прибора» для тёмного раздела) → четыре адресные карточки
  партнёрам — светлые плашки бумаги `#F3F3EF` с чернильным текстом.

## 3. Интерактивные устройства: что делают, без JS, при reduced-motion

Скрипт в `<head>` ставит класс `js` на `<html>`; всё, что имеет смысл только со скриптом, несёт класс `.jsonly`
и без JS не показывается. Клавиатура: все элементы — нативные `button` / `input` / `tr[tabindex=0]`, видимый
фокус `outline 2px` (`--ref-lt` на тёмном, `--ref` на плашке); `audit_build`: 40/40 и 39/39 остановок табуляции
с видимым фокусом. Ничего не движется само: анимаций нет, только переходы по действию (0 запущенных через 1,5 с).

## 4. Формулы

### Планшет ИФА 8 × 12 (принятая формула v2, NOTES_v2_kks5_motif.md; базовые единицы 560 × 340)

    r = 0…7 (ближний → дальний), c = 0…11, t = r/7
    q  = 1/(1 + 1,8·t),  q₇ = 1/2,8,  d = (1 − q)/(1 − q₇)
    x  = 280 + (c − 5,5)·42·q + shift·d          shift ∈ [−18; 18] — сдвиг точки схода от указателя (atan(18/250) ≈ 4,1°)
    y  = 310 − 250·d·(1 + lift)                  lift ∈ [0; 0,06] от прокрутки (+ ±0,02 от вертикали указателя)
    rx = 11·q,  ry = 7·q

Цвет по колонкам: 0–2 `#24305F`, 3–5 `#5282BE`, 6–8 `#97B5DC`, 9–11 `#A6B1BE`. Ореол — тот же цвет, 1,8·rx × 1,8·ry,
16 %. Лунка r = 0, c = 0 — отрицательный контроль: без заливки, белый контур 1,5 (rx, ry уменьшены на 0,75).
Контроль: well(0,0).cx = 49, well(7,0).cy = 60, rx₇ = 3,929 — совпадает с v2. На canvas: масштаб s = min(ширина
области/560, высота/340); область — правые 42 % героя с центром 0,77·W на ≥ 900 px, вся ширина на телефоне.
Горизонт на /rd — ряды r = 0, 1 той же формулы, `viewBox="0 220 560 101"`. Статические SVG: 96 эллипсов + 95 ореолов.

### Мотив программы вакцин для кур — линия поения и стадо (560 × 300)

    птицы — эллипсы, r = 0…5, c = 0…9, t = r/5, q = 1/(1 + 1,8·t), q₅ = 1/2,8, d = (1 − q)/(1 − q₅)
    x  = 280 + (c − 4,5)·52·q + 0,22·52·q·sin(3,7·c + 1,3·r)        детерминированный разброс стада
    y  = 272 − 205·d + 0,25·6,5·q·cos(2,1·c + 0,7·r)
    rx = 10·q,  ry = 6,5·q;  цвет: `#A6B1BE`, каждая птица с (c + r) mod 3 = 0 — `#97B5DC`
    линия поения — на глубине r = 2,5 (q = 1/1,9): труба от c = −0,5 до c = 9,5 цвета `#97B5DC`, толщина 3,2·q;
    ниппель в каждой колонке: штрих 9·q вниз и капля-эллипс rx 2,6·q, ry 3,6·q
    подсветка: прямоугольник 56 × 6 на трубе, translateX(p·450), p — доля прокрутки секции 0…1

Порядок слоёв: дальние птицы (r ≥ 3) → труба с ниппелями → подсветка → ближние птицы. Ни шприца, ни птицы-клипарта:
та же дисциплина эллипсов в перспективе, что у планшета.

### Ось хроники (560 × 28)

    x(день) = 20 + 520·день/64, дни от 27.08.2026: записи на 0, 5, 6, 8, 42, 50, 62; штрихи каждые 4 дня.
