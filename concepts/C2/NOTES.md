## 2. Что оставлено из «Прибора» и почему; что изменено

**Оставлено как есть**: первые три блока `<style>` версии 2 скопированы байт-в-байт (токены, шкала
кеглей, ритм 8 px, радиус 0, IBM Plex Sans / Mono, компоненты `.sh`, `.tbl`, `.spec`, `.card`,

гипотеза этой концепции — не другой стиль, а тот же прибор, включённый в сеть. Логотип и `#244191`
без изменений (`--ref` остаётся только для документных подчёркиваний и курсора хроники).

**Добавлено (четвёртый блок `<style>` + один инлайн-`<script>`)**: шкала под H1 рисуется по
делениям при загрузке; шкала заголовка раздела заполняется при входе в экран; индекс страницы;
органы управления `.ctl` (моно 13 px, рамка `--rule-2`, нажатый — чернила на бумаге) и видимый

(ось с делениями каждые 8 px, курсор — `--ref`); столбики КП `.kpbar`; мотив птичника `.vm`;
ярлык категории `.park__c`; печатная таблица стилей. Единственное отличие в тексте v2: в 03

## 4. Формулы графики

**Планшет ККС-5** (8 × 12, гамма № 3; колонки 1–3 `#24305F`, 4–6 `#5282BE`, 7–9 `#97B5DC`,
10–12 `#A6B1BE`; лунка r = 0, c = 0 — белая с обводкой navy 1,5 = отрицательный контроль).
Ряд r = 0…7 (ближний → дальний), колонка c = 0…11:

    q  = 1 / (1 + k·r/7),   q₇ = 1 / (1 + k)
    x  = 280 + (c − 5,5)·42·q
    y  = 310 − (310 − H)·(1 − q)/(1 − q₇)
    rx = 11·q,  ry = 7·q           (у отрицательного контроля минус 0,75)

В разметке k = 1,8, H = 60 — это ровно принятая формула версии 2 (сборка падает, если
well(0,0).cx ≠ 49 или well(7,0).cy ≠ 60, rx ≠ 3,929). С прокруткой: s = положение центра
планшета в экране (0 — у нижнего края, 1 — у верхнего), **k = 1,4 + 0,8·s, H = 90 − 60·s**;
при s = 0,5 геометрия версии 2. Горизонт (полоса из двух ближних рядов) — те же r = 0, 1 при
k = 1,8, H = 60, `viewBox="0 220 560 101"`.

**Столбики КП**: ширина = КП / 12 × 100 % (12 — верх шкалы, чтобы ≈11 поместилось);
4,4 → 36,67 %, 6,2 → 51,67 %, ≈11 → 91,67 %, 3,8 → 31,67 %; деление «порог 3» — 25 %;
анти-ВИЧ-1/2 — столбик во всю шкалу, штрихованный, со срезанным стрелкой правым краем:
«выше верхнего предела измерения фотометра». Заливка — цвет лунки маркера, обводка navy 1 px.

**Мотив птичника** (`viewBox 0 0 560 220`, только чернила и линовка: `#14171C`, `#454B55`,
`#5C636E`, `#B0B2AA`, белый; гамма № 3 не используется):

    подвесы:       x = 20 + 130·i, i = 0…4, y 0…26, `--rule-2`
    линия поения:  прямоугольник 20…540 × 26…32, обводка ink 1,5

    линия кормления: линия y = 92, 20…540, `--ink-2`

    пол:           линия y = 212, деления каждые 8 единиц (каждое пятое длиннее) — та же шкала, что под H1

**Ось хроники**: день d = дата − 27.08.2026, положение = d / 64; штрихи событий при d = 2, 5, 7,
